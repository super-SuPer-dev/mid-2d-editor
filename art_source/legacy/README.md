# Legacy Art Archive

This directory preserves superseded, unreferenced project art for provenance
and possible future review. Files here are excluded from Godot by the parent
`.gdignore` and must not be referenced by runtime scenes or scripts.

To reuse an archived asset, review and rename it to lowercase `snake_case`,
record its provenance and acceptance criteria, then promote it into `assets/`
through the validation process in `docs/PROJECT_STRUCTURE.md`.
